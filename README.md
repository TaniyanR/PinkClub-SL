# PinkClub-SL

SOKUMIRU商品検索APIを利用した、主要機能に絞った軽量アフィリエイト商品サイトです。

PinkClub-FLの画面構成・管理機能・SEO・アクセス解析を引き継ぎ、商品取得部分をSOKUMIRU WEBサービスへ置き換えています。

## 特徴

- PHP・MySQL（MariaDB）・JavaScriptで動作
- フレームワーク不使用
- PC・スマートフォン対応
- WordPress風の管理画面
- SOKUMIRU商品検索APIだけを使用
- アダルト動画（`av`）だけを取得
- cronによる商品自動更新
- 内蔵アクセス解析
- 商品ランキング
- 公開ページキャッシュ

## 対応API

- 商品検索API：`https://sokmil-ad.com/api/v1/Item`
- 出力形式：JSON
- カテゴリ：`av`固定
- 1回の取得件数：最大100件
- offset：1〜50000
- APIリクエストはプロセス間で1秒以上の間隔を確保
- HTTP転送は同一APIドメイン配下のHTTPS URLだけを許可

出演者検索API（`Actor`）や独立したジャンル・シリーズ等のAPIは使用しません。

## 商品情報から保存する関連名

商品APIの`iteminfo`から次の情報を保存します。

- 女優・出演者
- ジャンル
- メーカー
- レーベル
- シリーズ
- 監督

女優プロフィールや女優画像は保存しません。関連名は一覧と商品検索に使用します。

- 最近見た作品
- 出演者検索API

- シリーズAPI

- 女優プロフィールと女優画像の保存
- 商品以外の個別詳細ページ

商品詳細ページのサンプル画像とサンプル動画は残しています。

## 検索と一覧

女優・ジャンル・メーカー・レーベル・シリーズの名称一覧を表示します。名称を選択すると、共通の商品検索結果へ移動します。

検索は`raw_json`全体を走査せず、商品タイトル・商品ID・商品APIから保存した関連名を対象にします。

## ランキング

商品ランキングだけを表示します。

- 本日
- 週間
- 月間
- 年間

ランキングは30分キャッシュし、更新中も古いキャッシュを表示します。

## セットアップ

1. サーバーへファイル一式をアップロードします。
2. ブラウザで`/public/setup_check.php`を開きます。
3. DBホスト名・ポート・DB名・ユーザー名・パスワードを保存します。
4. 「セットアップを実行する」を押します。
5. `/public/login0718.php`から管理画面へログインします。
6. 初期管理者パスワードを必ず変更します。

初期管理者は`admin`、初期パスワードは`password`です。

## API設定

管理画面の「商品情報API設定」で次を保存します。

- API KEY
- アフィリエイトID

認証情報はGitへ保存しません。環境変数を利用する場合は、`SOKUMIRU_API_KEY`と`SOKUMIRU_AFFILIATE_ID`を指定できます。API側で参照元URLの登録が必要な場合は、`SOKUMIRU_REFERER`に公開サイトのURLを指定できます（未指定時はサイトURLを使用します）。

## 自動更新

自動更新はcron専用です。公開ページや管理画面へのアクセスでは商品同期を開始しません。

```bash
php /path/to/PinkClub-SL/scripts/auto_import.php
```

推奨cron間隔は10分です。実際の商品取得間隔と取得件数は管理画面から設定できます。

## 固定URL

- 公開トップ：`/public/`
- 管理ログイン：`/public/login0718.php`
- 管理トップ：`/admin/index.php`
- セットアップ確認：`/public/setup_check.php`
- 商品API設定：`/admin/api_items.php`
- 自動設定：`/admin/api_auto.php`
- アクセス解析：`/admin/analytics.php`

## データ保存方針

- SOKUMIRU商品IDを一意キーとしてupsert
- APIレスポンスを`items.raw_json`にも保存
- 商品に含まれる関連名を各`item_*`テーブルへ保存
- 外部画像・動画はSOKUMIRU提供URLを使用
- API KEYとアフィリエイトIDはAPIログでマスク
- 商品リンクの中継先は`*.sokmil.com`だけを許可
- `/limited_item/`のキャンペーンページは通常商品として登録・公開しない

## クレジット

公開ページのフッターにSOKUMIRU指定の`WEB SERVICE BY SOKMIL`クレジットを表示します。

## 開発方針

- PinkClub-FLの既存デザインと主要機能を維持
- 不要な全面リファクタリングを行わない
- 作業ブランチとDraft PRを使用
- 確認前に`main`へマージしない
- 外部画像や動画の利用条件を守る
